007 像书一样翻开的卡片

卡片是产品里最容易撞脸的元素。圆角、图标、标题、描述和一行 meta，几乎所有产品都能拼出相似的一组。

想让它有一点自己的性格，不必更换整个卡片系统。更克制的做法是：静止时完全保持原样，只有在悬停或键盘聚焦时，才像一本小书一样翻开一点，露出里面的几页。

静止时不能有任何变化

这个效果的前提是“藏”。卡片在静止状态下必须和原来的卡片一模一样：尺寸、内边距、文字、图标和布局都不变，周围元素也不能因为悬停而移动。

卡片本身的占位不参与 3D 运动。真正翻动的是内部图层：

封面承担原有卡片内容，内页和封底只是装饰，设置为 aria-hidden，不包含链接，也不进入 Tab 顺序。整张卡片仍然是一个完整的链接或按钮。

图层与铰链

封面、内页和封底都绝对定位在同一个方形区域内。外层容器提供约 1100px 的透视，铰链在左、右或上边缘，内部的每一层再使用相同的 transform-origin。

每个图层还需要一点 translateZ 偏移，避免翻开时互相打架：

内页比封面向内缩 8px，靠书脊一侧再收 4px，圆角使用“封面圆角 − 8”。封底在平面卡片上向内缩约 6px，圆角同步减去 6；拟物风格则可以与封面齐平，并直接使用封面色的暗调。

扇形展开，而不是一起旋转

封面先动，后面的内页依次跟随。设封面为 n = 0，内页为 1…N：

每一层都用自己的弹簧收敛，大约 0.3 秒稳定。关闭时顺序反过来，最里面的页面先合上：

如果指针在动画中途离开，要从当前角度和速度重新设定目标，而不是回到起点重播。动作被打断时也不能跳帧。

项目没有弹簧工具时，可以用约 420ms 的 CSS 过渡近似，例如 cubic-bezier(0.3, 1.2, 0.5, 1)。

阴影要像实体，不能像描边

阴影是这类效果最容易露馅的部分。

不要用 box-shadow 画翻开的卡片阴影：它本质上是一圈中空的环，封面一旦离开原位，就会露出不自然的边框。

正确做法是在卡片后面放两层实心、预先模糊的阴影形状：

  • 接触阴影：较小、较深，贴着卡片底部；
  • 环境阴影：更淡、更柔，向下偏移。

静止时使用短而紧的一组；翻开时交叉淡入更长、更柔、更靠下的另一组。由于阴影已经预先模糊，动画只改变 opacity 和 transform，不逐帧修改模糊半径。

光源统一从上方来。阴影颜色应接近墙面，可以稍微偏暖或偏冷，但不要用纯黑，也不要用高饱和色。

每一页还需要一层“叶影”：前一页刚刚抬起时，后一页被压暗；两页分开后，再逐渐恢复亮度。这个明暗变化会让页面之间产生真实的间距感。

边缘和焦点属于同一套几何

封面、内页和封底必须共用同一套裁切路径。边框也应该沿着这条路径绘制，而不是混用 CSS border、inset shadow 和 clip-path——不同渲染方式在圆角处会出现第二道边。

如果要使用连续曲率，可以生成对应的超级椭圆路径，并让裁切和描边复用同一个路径。圆角、内页缩进和封底缩进都必须来自同一套 radius token。

交互命中区域要保持在卡片静止时的外框上。所有运动图层都设置 pointer-events: none，否则翻开的封面会在鼠标边缘来回触发，导致卡片抖动。

键盘聚焦应与悬停打开同样的状态，焦点环留在外层卡片上。开启减少动态效果时，取消扇形展开，只让封面轻轻抬起约 2px，并让阴影切换到翻开状态；触摸设备则确保第一次点击就能触发卡片，而不是把第一下点击只用来模拟悬停。

性能边界

只动画 transform 和 opacity。

不要动画 blur、box-shadow、clip-path、宽高或 top/left。阴影模糊只计算一次，之后交叉淡入淡出。

多张卡片共用一条 requestAnimationFrame 循环；弹簧静止的卡片跳过，所有卡片都停下时停止循环。每帧不读取布局，尺寸只在初始化和 ResizeObserver 触发时测量。

如果封面使用动态 ASCII 场景，画布最多约 30fps，并在离开屏幕或标签页隐藏时暂停。

三种视觉风格

同一套运动可以套进三种风格：

  • Default：普通产品卡片，白色表面、细边框、48px 图标、标题和描述；
  • Skeuomorphic：精装书，布纹封面、受光倒角、暖灰阴影、奶油色纸张；
  • Minimal：文档册，冷白或石墨色表面、等宽编号、细线图和灰色正文线。

风格只改变材质、排版和封面内容，不改变翻页的因果结构。卡片原有的 surface、border、shadow、radius 和 motion token 应优先复用。

质感来自可解释的细节

翻页卡片真正高级的地方，不是旋转角度有多大，而是静止时完全藏住、打开时每一层都有明确关系、关闭时还能顺手收回。

封面、页面、阴影、圆角和焦点共同遵守一套空间规则，卡片才会像一本可以拿起来的小书，而不是一组为了动而动的 3D 图层。
