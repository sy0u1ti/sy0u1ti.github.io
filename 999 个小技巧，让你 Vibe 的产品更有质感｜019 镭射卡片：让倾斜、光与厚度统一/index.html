019 镭射卡片：让倾斜、光与厚度统一

镭射卡片很容易做得很“亮”，却不一定很像一张真实存在的卡。

只给表面叠一层彩虹渐变，卡片仍然是平的；只让卡片跟着鼠标旋转，却没有光、没有视差、没有边缘厚度，它也只是斜着的一块 UI。

真正的全息卡需要三件事一起成立：材料的颜色随光移动、卡片内部有深度、物理边缘在翻面时能被看见。

一张屏幕只留一张可以发光的卡

镭射效果表达的是身份、所有权或稀缺性，例如会员卡、门票、通行证、成就、档案卡与收藏卡。

如果页面里的每张卡都在反光，反而没有一张值得被看见。默认应该只选择一张“代表用户是谁或拥有什么”的卡，而不是把所有内容卡片都升级成全息材质。

卡片原有文案与动作不变。效果是表面与反馈的增强，不是改版，更不是把所有按钮都变成可翻转玩具。

六个面，先定材料再定动效

Prism

深蓝玻璃从内部发光，是默认推荐。

高光区域使用多层径向渐变与蓝绿色光晕，而不是几个孤立亮点。近光处出现粉紫、青色与薄荷绿，远离光点后逐渐压回深蓝。

它适合大多数偏科技、会员、通行证的产品。

Rainbow

彩虹色带随倾斜滑动，再叠一层细密光栅，让颜色被切碎成金属反射。

它最戏剧化，适合庆祝、特殊等级或一次性票据，不应该成为日常通用材质。

Pearl

白色或冷白珠光表面，彩色光泽更像边框与掠射，而不是整张卡片浓烈变色。

Pearl 的克制感适合日常会员卡与高价值但不需要张扬的场景。

Sparkle

细碎闪点分布在卡片表面，两套不同角度的彩色箔面以 screen 混合叠在闪点上。

关键是暗色间隙。每个闪点应该有自己的受光角度，亮起后再次熄灭，而不是整片均匀发亮。

Chrome

银色金属镜面，高光方向与倾斜相反，并带有雕刻般的文字阴影。

Chrome 适合硬件、潮流或具有收藏属性的卡片，但文字必须始终保持清楚。

Etched

哑黑表面上有极细的同心环。平时几乎看不见，只有光线经过时，环与彩色箔面才短暂显现。

Etched 很适合低调、神秘、偏专业的产品，也提醒设计者：镭射不一定等于高饱和。

一张卡片由五层正面组成

无论选择哪种材质，卡片的正面都按从后到前排列：

  1. Art：原本的底色或插画；
  2. Foil：材质箔面；
  3. Print：文字、Logo、内容窗口与所有需要阅读的信息；
  4. Glare：以光点为中心的白色高光与远端暗角；
  5. Rim：约 1.5px 的亮边，只在靠近光点的一段出现。

Print 必须位于 Foil 之上。只要反射盖住文字，材料就失败了。

Rim 不能看起来像一圈固定描边，而应该随着卡片移动忽明忽暗。靠近光源的一段被点亮，其余边缘退回很淡的底色。

如果卡片有全息封印，可以使用小型彩色圆盘，再叠加细密同心环。它的角度跟随光点与卡片旋转，但面积要小，不能抢过主画面。

指针离开后允许轻微过冲再回正。光点也跟随指针，但使用无过冲弹簧，默认 stiffness 160、damping 约 25.3。

用户没有操作时，卡片不能完全静止成一张平面图。它应该像被人拿在手里一样轻微摆动：

光点随摆动同步移动。卡片下方再放一层模糊椭圆阴影，阴影向抬起的一侧偏移，让倾斜有真实重量。

视差要服从真实深度

卡片内部元素不是一起随外壳平移，而是根据各自深度产生视差。

设元素在卡面后方的深度为 d，负值表示位于卡面前方：

这相当于用真实 3D 的方式移动各层。演示中，背景图在 90px 后方，表盘 50px，中层圆环 34px，虚线环 20px，指针在 -12px；角落文字则贴在卡面，不产生视差。

最靠后的图层要比可见窗口更大，四周至少多出 100px，否则倾斜时会露出裁切边缘。

视差不能无穷叠加。一个卡片最多保留一种会自行活动的核心元素：

  • 指针向鼠标方向弹性转动；
  • 表盘缓慢旋转；
  • 虚线环朝相反方向转动。

其他层只跟随倾斜，保持背景深度。

翻面必须露出厚度

点击、轻触或键盘 Enter / Space，卡片绕垂直轴翻转 180°。

默认使用 stiffness 70、damping 11 的弹簧，约 0.8 秒完成，并在结尾有一点点过冲。卡片翻到侧边时向前抬起：

厚度默认 10px：

  • 正面在卡片中轴前 5px；
  • 背面在中轴后 5px，并旋转 180°；
  • 中间均匀堆叠 10 层卡片轮廓，使用材质的边缘色；
  • 两张面都设置 backface-visibility: hidden；
  • 边缘层只在翻面期间绘制。

背面需要继承相同的 Foil、Glare 与 Rim，但光点方向左右镜像。任何只在正面变化的材质或内容，都必须在卡片侧对屏幕时切换，不能让用户看到突然替换。

快速连续点击时，卡片不能同时露出两面，也不能在侧边出现空隙。

背景是可选层，不要默认加满

大多数产品只需要卡片本身。卡片后方保持原页面即可。

如果需要更强氛围，可以加一层柔和的同色光晕，或者低频流动的背景。默认推荐不改造页面背景，因为卡片的反射已经足够表达材质。

一旦增加流体背景，要注意它与卡片的倾斜同步，并降低分辨率、约 30fps 渲染。背景是为了托住卡片，不是另一段主视觉动画。

预设用来控制强度，不用来堆选项

动势

  • Quiet：6°，弹簧 120 / 18，摆动约 1–1.5°；
  • Standard：12°，弹簧 140 / 15，摆动 2–3°；
  • Lively：16°，弹簧 180 / 12，摆动 3–4°。

厚度

  • Thin：6px，6 层；
  • Standard：10px，10 层；
  • Thick：16px，16 层。

翻面弹簧

  • Soft：55 / 9；
  • Standard：70 / 11；
  • Crisp：110 / 18。

深度

  • None；
  • Subtle：所有深度减半；
  • Standard：按真实层级设置。

一种适合日常产品的搭配是 Pearl + Quiet；Rainbow 和 Sparkle 可以配 Standard 或 Lively，用于真正值得庆祝的瞬间。

可访问性优先于“炫”

减少动态效果时，关闭倾斜、闲置摆动与翻面动画。翻面可以直接交换内容，或用约 200ms 淡入淡出；光仍可以跟随指针，但背景保持静止。

卡片原本是链接就保持链接，是按钮就保持按钮。背面必须能通过键盘到达并有明确名称。任何关键信息都不能只在一个角度可见。

每种材质都要检查四个角与中心：

  • 文本在箔面最亮和最暗时仍然清楚；
  • 高光不冲掉印刷内容；
  • Rim 不会变成实线；
  • 深色与浅色页面都成立。

先确认选项，再实现

在修改代码前，需要先查看卡片的组件、尺寸、圆角、内容、是否已有背面，以及平台、输入方式和现有动效 token。

然后逐项确认：

  1. 哪一张卡承担身份或所有权；
  2. 使用哪种材质，是否需要多档等级；
  3. 动势选 Quiet、Standard 还是 Lively；
  4. 是否开启指针倾斜、闲置摆动、翻面与手机动作感应；
  5. 翻面时的厚度与弹簧；
  6. 哪些插画元素拥有独立深度；
  7. 是否改造卡片背后的页面氛围。

最后用一张表汇总选择，说明实现平台、成本与回退，再开始。

检查清单

  • 一屏是否只强调一张具有身份意义的卡；
  • 材质是否由 Art、Foil、Print、Glare、Rim 正确叠层；
  • 文字是否始终位于箔面之上并保持可读；
  • 倾斜是否限制在合理角度，离开时有轻微回弹；
  • 闲置摆动是否缓慢，光点是否与卡片一起移动；
  • 内部元素的深度是否遵循同一视差公式；
  • 翻面是否露出真实厚度，背面是否同步材质与光照；
  • 快速连续翻面是否不露缝、不叠面；
  • 减少动态效果与键盘操作是否完整；
  • 运行是否由单一 requestAnimationFrame 驱动，并在离屏时停止。

质感来自可解释的细节

全息卡片的复杂度不应该体现在特效数量，而应该体现在所有层是否服从同一束光。

箔面决定材料，Glare 决定光从哪里来，Rim 说明边缘如何受光，视差把内部画面放进同一空间，翻面时再让卡片露出真实厚度。关系一致之后，一张网页卡片才会像可以拿在手里的物件。
