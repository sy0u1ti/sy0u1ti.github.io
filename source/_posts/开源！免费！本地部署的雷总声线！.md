基于开源顶尖少样本声音克隆项目 **GPT-SoVITS**，结合社区微调好的雷军（雷总）专属声音权重，只需准备几秒参考音频，就能在本地完全离线生成高度逼真、语气极其神似的“Are you OK”雷氏演讲声线。

## 安装与环境配置

解压整合包后，在整合包根目录下打开命令提示符（CMD），使用国内清华源补齐依赖：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**模型权重放置**：
将从网盘下载解压出来的 `weights` 文件夹中的模型文件，对应拷贝到整合包目录内的 `GPT_SoVITS/pretrained_models` 或 `weights` 目标路径中。

## 启动与推理操作

### 1. 启动 WebUI 界面

双击运行整合包根目录下的 `go-webui.bat`。控制台加载完成后会自动唤起浏览器打开：
[http://localhost:9874/](http://localhost:9874/)

在主界面中：
1. 点击顶部标签页 **1-GPT-SOVITS-TTS**。
2. 勾选 **启用并行推理版本**（可显著提升 GPU 推理响应速度）。
3. 点击 **开启 TTS 推理 WebUI**，系统会弹出新的独立推理界面。

### 2. 调优参数（逼真度核心秘诀）

在新打开的推理控制台中：
- **模型选择**：在左侧权重下拉菜单中选择雷总的 GPT 权重（如序号 14），右侧选择对应的 SoVITS 权重（如序号 12）。
- **参考音频选择**：在附带网盘的 `output/denoise_opt/` 中挑选一段雷总的清晰原声音频（时长建议控制在 3~8 秒内），并在上方文本框输入该音频对应的文字内容（参考文本见 `output/asr_opt/denoise_opt.list`）。
- **关键音色调节**：
  - **语速系数（speed_factor）**：设为 `0.95`（语速略慢一点，更贴合雷总稳重儒雅的说话习惯）。
  - **分段切分间隔**：设为 `0.25` 秒。
  - **Batch Size**：如显卡显存为 6G（例如 RTX 2060）可拉到 `60`，大幅提升批量生成效率。

### 3. 目标文本断句规范

GPT-SoVITS 对标点符号和单行长度较为敏感。建议采用短句换行，避免超长复合句一口气读完：

**推荐格式（按语义节奏断行）：**
```text
不觉得这很酷吗
这真的太酷了
科技并伴有趣味
很符合我对未来的想象。
```

点击底部的 **合成音频**，试听满意后即可直接一键下载 WAV 文件。
